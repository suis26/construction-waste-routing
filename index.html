CONSTRUCTION WASTE ROUTING

建筑垃圾运输优化平台 源头识别 · 接收匹配 · 车辆协同调度

先在源头确认材料与接收条件，再联合决定去向、车辆与时间，避免车开到门口才发现收不了。本页为可直接部署到 GitHub Pages 的成果索引，含交互式调度 Demo、算法方案与参考实现。

▶ 打开动态调度 Demo 查看成果文档

核心能力

  1. 源头识别与分诊：识别材质标签与置信度，低置信度或异常订单自动复核，且仍保证排入最终计划。
  2. 接收匹配：材质须落在设施接收目录内，类别须允许该类设施，泥浆强制先进预处理站。
  3. 联合调度：选车辆、选去向、排装卸顺序、定到场时刻，并计入路况与处理难度。
  4. 前瞻合并：估算当前任务完成后车辆可用时刻对后续任务花费的影响，综合评价后再合并。
